Email 簽名檔產生器

同事在網頁填寫姓名、部門、職稱、分機，即可產生公司統一格式的 Email 簽名，
複製後貼到 Outlook 簽名設定使用。

目前測試網址：https://ssunshine0608.github.io/signature/
原始碼：https://github.com/ssunshine0608/signature


========================================
架設需求（給 IT）
========================================

- 純靜態網頁：只有 index.html 和 assets/ 資料夾。
  不需要後端程式、資料庫、PHP 或 Node.js，任何能放靜態檔案的空間都可以
  （公司網站主機、IIS、Nginx、Apache、NAS 網頁服務、GitHub Pages 等）。
- 必須使用 HTTPS 網址。
  「複製簽名檔」用到瀏覽器的剪貼簿功能，瀏覽器只在 HTTPS 頁面開放這個功能。
- 不能直接雙擊 index.html 開啟（file://），瀏覽器會封鎖圖片輸出。
- 對外連線：網頁會從 Google Fonts（fonts.googleapis.com、fonts.gstatic.com）
  載入思源黑體。若公司網路擋這兩個網域，網頁仍可使用，但字型會改用電腦內建字型，
  排版可能略有差異。
- 資料不會上傳：所有圖片都在使用者的瀏覽器內產生，伺服器不會收到或儲存任何個人資料。
- 檔名 assets/weblink x adobe.svg 含空白、assets/通用簽名檔橫幅.svg 為中文，一般伺服器都能正常提供；
  若上傳工具不接受，改檔名後需同步修改 index.html 裡 COMPANY.assets 的對應檔名。
- 本機測試：在專案資料夾執行 python3 -m http.server，再開 http://localhost:8000


========================================
檔案
========================================

- index.html                      網頁本體（含所有程式與樣式）
- assets/weblink x adobe.svg      右上 Logo
- assets/pic.svg                  右下裝飾圖
- assets/icon-phone.png           電話小圖示
- assets/icon-pin.png             地址小圖示
- assets/icon-web.png             網站小圖示
- assets/rainbow-line.png         彩虹線
- assets/LINE.png                 LINE 官方帳號 QR Code（含綠框）
- assets/通用簽名檔橫幅.svg        底部橫幅。顏色由程式依設定替換；
                                  小字與「立即查看 →」由程式畫出（SVG 內的小字會被忽略）
- assets/icon-web.png、icon-mail.png  目前沒有使用


========================================
簽名檔內容
========================================

- 一張簽名圖片，可選兩種尺寸：標準版 450×194、大版 600×258。
- 可選靜態（PNG，預設）或動畫（GIF）：動畫為兩格、每格 1 秒，
  第二格按鈕微微放大、箭頭變紅右移。舊版 Windows Outlook 只顯示第一格（畫面完整）。
  GIF 無法寫入解析度，複製時以 HTML 指定顯示寬高；GIF 最多 256 色，
  右側漸層裝飾圖以混色處理。按鈕第二格樣式可在 index.html 的 BTN_FRAME2／btnStyle2 更換。
  圖片實際像素皆為 1200×516，檔案內依尺寸寫入 256／192 DPI，
  Outlook 會自動以對應寬度顯示，不需手動縮小。
- 圖片內容：姓名、其他名稱、部門｜職稱、電話分機、公司地址、
  LINE 官方帳號 QR Code，以及底部「探索 Adobe 最新資訊」橫幅。
- 點整張圖片會開啟官網 https://adbecsp.weblink.com.tw/（可在網頁上自訂）
- 圖片下方一行可點擊的文字「技術信箱：adbeservice@weblink.com.tw」，
  點了會開新信件；收件人的信箱擋圖片時，仍看得到、點得到技術信箱。


========================================
使用方式（同事）
========================================

1. 開啟網頁，選擇公司據點（台北總公司／台中營業據點），地址與電話會自動帶入。
   姓名為必填，其他名稱、部門、職稱、分機為選填。
2. 選擇圖片尺寸：標準版或大版。
   需要時可展開「自訂橫幅與連結」，修改橫幅小字、點圖片開啟的網址
   （官網／經銷商名錄／自訂；選經銷商名錄時按鈕會變成「聯繫經銷商 →」）、
   橫幅底色／兩個圓形／文字顏色（也有幾組現成配色），「還原預設」可回到公司預設。
3. 點「複製簽名檔」，依網頁上的步驟貼到 Outlook 簽名設定。
4. 需要單獨的圖片檔時，可用「下載圖片檔」。
5. 圖片樣式可選「靜態（PNG）」或「動畫（GIF）」，複製與下載都會依這個選擇。


========================================
維護
========================================

- 技術信箱、網站（圖片連結預設值）、LINE 旁的文字、橫幅按鈕文字：
  index.html 裡的 COMPANY 設定，改一次全員適用。
- 橫幅預設小字與預設配色：COMPANY.banner；現成配色選項：PRESETS。
- 網址選項（官網、經銷商名錄）與各自的按鈕文字：COMPANY.links。
- 各據點地址與公司電話：COMPANY.offices。新增據點時，除了 offices 再加一筆，
  也要在 index.html 表單的「公司據點」多加一個選項（value 對應 offices 的名稱）。
- 各元素位置：index.html 裡的 LAYOUT 設定（以 600×258 為基準）。
- 換 QR Code 或橫幅：直接覆蓋 assets/LINE.png、assets/通用簽名檔橫幅.svg。
  橫幅 SVG 若比例改變，需一併調整 index.html 的 H（圖片總高度）。
- 兩種尺寸：index.html 裡的 SIZES 設定。
- Logo 與裝飾圖是 SVG 向量檔（文字已轉外框），換圖時直接覆蓋同名檔案即可。
- 小圖示與彩虹線是低解析 PNG，之後可換成 SVG，並修改 COMPANY.assets 的檔名。
- 修改後同事需重新產生並貼上簽名，已貼在 Outlook 的舊簽名不會自動更新。
