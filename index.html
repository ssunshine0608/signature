Outlook 設定方式
先複製簽名檔，再到 Outlook 貼上。
Windows 傳統版 Outlook
  1. 左上角「檔案」→「選項」。
  2. 左側選「郵件」，再點右邊的「簽名...」。
  3. 點「新增」，輸入簽名名稱（例如：公司簽名）。
  4. 在下方編輯區貼上（Ctrl + V）。
  5. 右側「選擇預設簽名」：新郵件、回覆/轉寄都選這個簽名。
  6. 點「確定」儲存。
新版 Outlook／網頁版 Outlook
  1. 右上角齒輪「設定」。
  2. 選「帳戶」→「簽章」。
  3. 點「新增簽章」，輸入名稱。
  4. 在編輯區貼上（Ctrl + V）。
  5. 下方「選取預設簽章」：新郵件、回覆/轉寄都選這個簽名。
  6. 點「儲存」。
Mac 版 Outlook
  1. 螢幕最上方選單「Outlook」→「設定」。
  2. 點「簽名」。
  3. 點左下角「＋」新增，輸入名稱。
  4. 在編輯區貼上（⌘ + V）。
  5. 下方「選擇預設簽名」：新郵件、回覆/轉寄都選這個簽名。
  6. 關閉視窗即自動儲存。
